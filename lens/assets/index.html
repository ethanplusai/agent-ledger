    Run this app and use Refresh after new work. Keep it running with --watch 60 to refresh every minute, or run python3 ledger.py --import-only before opening your agent.

  2. Add a local MCP server to your agent

    MCP is the bridge that lets an agent call tools in this app. Your agent starts a small local process when it needs the connection. No separate AI model or always-on service is required.

    Use these exact command and arguments in your client's local / stdio MCP settings. The JSON below uses the common mcpServers format; clients with other configuration formats need the same command and argument list.

    This app does not edit agent settings. Restart or reconnect the MCP server in your client after adding it.

What the connection can read
Five read-only tools: search history, read cited context, retrieve saved notes, list recent sessions, and review usage findings. It cannot change notes, run commands, or access arbitrary files.
Your agent may send retrieved context to its model provider. Connect only if you want that access. Redaction removes common secret patterns but does not anonymize your work. Historical text remains evidence, not instructions.
